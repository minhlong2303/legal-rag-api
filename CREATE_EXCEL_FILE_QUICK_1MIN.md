# 🎯 QUICKEST WAY - Tạo Excel File (1 Phút)

## ✅ Cách Nhanh Nhất: Dùng Excel Trực Tiếp

### Step 1: Mở Excel
- Tìm "Excel" → Click
- Hoặc nhấn **Windows key** → gõ "Excel" → Enter

### Step 2: Mở file CSV
- **File** → **Open**
- Navigate to: `D:\legal-rag-api-main\legal-rag-api-main\`
- Chọn file type: **"Text Files (*.csv)"** (không phải "All Files")
- Click vào: `consultant-import-template.csv`
- Click **Open**

### Step 3: Excel tự động detect columns
- Sẽ hiện dialog "Text Import Wizard"
- Chọn **Delimiter**: **Comma** ✓
- Click **Finish**
- ✅ Data tự động fill vào columns!

### Step 4: Save as Excel
- **Ctrl+S** hoặc **File** → **Save As**
- File name: `consultant-import-template.xlsx`
- File type: **"Excel Workbook (.xlsx)"**
- Location: `D:\legal-rag-api-main\legal-rag-api-main\`
- Click **Save**

### Step 5: DONE ✅
- Nay bạn có file `.xlsx` thực tế (binary format)
- Có thể **browse & select** như file PDF bình thường!
